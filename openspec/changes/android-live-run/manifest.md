# Requirements manifest — android-live-run

Источник: живой прогон на этом железе невозможен без гипервизора; оператор ответил:
«Реализуй, а протестирую я на другом железе. Где это будет работать», engine — «Качать сейчас фоном»,
adb — «Добавить platform-tools ассет», сеть — «Без прокси, blocked».

| ID | Требование | Цитата оператора |
|---|---|---|
| R01 | Движок скачивается и ставится через существующий `ensureAndroidEngine`, с прогрессом в UI (`engine/install`) | «Качать сейчас фоном» |
| R02 | `platform-tools` (adb) — пиннед-ассет движка: `resolveAdbPath` обязан находить adb после установки, иначе живой прогон невозможен физически | «Добавить platform-tools ассет» |
| R03 | Пинinned-ревизия эмулятора обновляется: `16349944` отсутствует в живом `repository2-3.xml`; пиннится существующая ревизия с её SHA-1/размером | «Реализуй» (реализация под живое железо) |
| R04 | Перед скачиванием ~2 ГБ UI показывает честную префлайт-проверку гипервизора (`assertHypervisorReady` через engine-status/install), а не молчаливый провал на спавне | «Где это будет работать» |
| R05 | Первый живой прогон — профиль без прокси в `blocked`-режиме: boot → inject → stream проверяются без внешнего прокси | «Без прокси, blocked» |
| R06 | Тестирование — на другом железе оператора: код обязан держать юнит-зелень здесь, живой прогон — там | «а протестирую я на другом железе» |
| R07 | Desktop-путь не регрессирует: все существующие тесты зелёные | инвариант репозитория |
